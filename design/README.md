# Vaani HUD Design (Phase 2 ke liye)

- `vaani-hud-design.html`: editable design file. Ise Chrome/Edge mein kholo, aur 1–5 keys ya upar-right buttons se screens badlo.
- Design badalna ho: file ko VS Code/Notepad mein kholo.
  - Colours, transparency, mic ki jagah, card size, core size: `:root` block ("YAHAN SE DESIGN BADLO")
  - Agent ka naam / wake word: `AGENT_NAME`, `WAKE_WORD`
  - Sample cards: `const DATA`
- `01-idle.png` … `05-full.png`: current design ke screenshots.

Fonts (Orbitron, Rajdhani, JetBrains Mono) file ke andar hi embedded hain, isliye internet ke bina bhi chalega.
